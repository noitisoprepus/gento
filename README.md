# Gento

Gento is a small CLI AI agent written in C# for .NET 10. It is designed for interactive terminal chat with local and cloud models through Ollama.

## Why I made this project

Gento is a learning project to understand how AI agents work. Writing the implementation myself lets me follow what happens between a prompt and the final answer, including how the model requests a tool and uses its result.

This app is not intended as an alternative to mainstream AI agents.
